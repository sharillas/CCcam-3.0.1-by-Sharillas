# CCcam3 - Servidor de Cardsharing Next Generation

## Descrição
CCcam3 é uma reimplementação moderna do protocolo CCcam, com suporte a encriptação melhorada, cache de CWs e arquitetura modular.

## Características
- Suporte a clientes CCcam existentes (compatibilidade retrógrada)
- Múltiplos modos de encriptação: RC4, AES, 3DES
- Sistema de cache de Control Words
- Logging configurável
- Design modular e extensível
